# KnowledgeNestEDU

An account-free, school-style learning dashboard with math practice, a calculator, a class schedule, homework tracking, and locally saved progress.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server. The optional browser game player needs an internet connection to load.

## Features

- Arithmetic practice with a saved count of correctly answered questions.
- A student dashboard with attendance, a sample class schedule, subjects, and a homework checklist.
- Progress and planner checkboxes saved in local browser storage; no account or sign-in required.
- A bonus browser activity is available after completing the practice goal.

The browser player currently supports Game Boy Advance. Nintendo 3DS games are not supported in this browser-based player. No game files are included; use only files you have the right to use.
