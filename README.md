# KnowledgeNestEDU

A small, static educational site with a practice quiz, calculator, and an unlockable browser-based GBA emulator.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server. The emulator player loads from the EmulatorJS CDN, so an internet connection is needed for that feature.

## Features

- Arithmetic practice with a saved count of correctly answered questions.
- Unlock the game corner at 50 correct answers, or enter `123` in the calculator and hold **Enter** and **-** together for 3 seconds.
- Choose a GBA ROM file from your device. The ROM is read by the browser and is not uploaded by this site.
- Quiz progress and the secret unlock are stored in local browser storage. Emulator save options and game saves are handled locally by EmulatorJS.

Only use ROMs you have the legal right to use. No game ROMs are included.
