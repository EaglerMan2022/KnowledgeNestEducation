# KnowledgeNestEDU

A simple, account-free learning space with arithmetic practice, a calculator, and locally saved progress.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server. The optional interactive activity needs an internet connection to load its player.

## Features

- Arithmetic practice with a saved count of correctly answered questions.
- Reach 50 correct answers to complete the learning goal and access additional resources.
- Quiz progress and activity unlocks are stored in local browser storage.
- No account or sign-in required.

Your progress stays in this browser on this device.
